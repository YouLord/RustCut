# RustCut

Экспериментальный видеомонтаж на Rust.

Независимый прототип монтажного движка с рабочим интерфейсом в браузере. **Это не Adobe Premiere Pro и не переписанный исходный код Adobe:** исходников Premiere в этом репозитории нет. Совместимость с `.prproj`, плагинами Premiere и другими закрытыми форматами не реализована. Ускорение относительно Premiere не измерялось: само по себе использование Rust его не гарантирует.

Проект называется **RustCut**. Если в адресе репозитория ещё встречается старое имя `Adobe-Premiere-Pro-rust`, оно историческое и не означает принадлежности к Adobe или совместимости с Premiere.

## О переносе существующего приложения

[rust-anything](https://github.com/erkamyaman/rust-anything) помогает планировать перенос исходного кода, создавать обвязку и сравнивать Rust-версию с записанным поведением оригинала. Сам Rust-код всё равно пишет разработчик или агент, а проверка охватывает только записанные случаи. По [FAQ проекта](https://github.com/erkamyaman/rust-anything/blob/main/docs/faq.md) инструмент не переносит приложение из одного `.exe`: для применения к Premiere потребовались бы доступные на законных основаниях исходники и работающий оригинал. В этом репозитории их нет.

## Что уже работает

- Демонстрационный проект с тремя короткими видеоклипами и синтезированным звуком.
- Импорт видео и аудио (до 100 МБ на файл, не длиннее 1 часа); определение потоков и длительности через `ffprobe`, миниатюры и аудиоволна через `ffmpeg`.
- Последовательность 25 fps с одной видеодорожкой **V1** и одной аудиодорожкой **A1**. Клипы хранятся в целых кадрах, с непересекающимися интервалами на каждой дорожке.
- Выделение, перемещение, обрезка за края, разрез по курсору, удаление, привязка, отмена и повтор. Двойной щелчок по медиа добавляет его в конец дорожки; перетаскивание на V1/A1 добавляет в выбранную позицию, если там достаточно места.
- Предпросмотр в браузере, включая звук V1 и A1; отображение реальной волны аудиопотока.
- Явное сохранение одного проекта на **сервере, где запущен RustCut**, и его восстановление при перезапуске.
- Экспорт монтажной последовательности в **H.264/AAC MP4, 1280×720, 25 fps** через FFmpeg. Промежутки заполняются чёрным кадром и тишиной. Рендер выполняется по снимку проекта на момент нажатия кнопки.

Интерфейс здесь реализован на HTML/CSS/JavaScript, чтобы прототип можно было запустить и проверить в браузере; это **не обещанный ранее интерфейс на egui**. Логика клипов, сохранение проекта, HTTP-сервер и построение задания рендера написаны на Rust. Декодирование/кодирование выполняет внешний FFmpeg, а предпросмотр — браузер, поэтому поддерживаемые браузером кодеки могут отличаться от поддерживаемых FFmpeg.

## Запуск

Нужны Rust **1.82+**, `cargo`, а для импорта и экспорта — `ffmpeg` с `libx264` и `ffprobe` в `PATH`. На Debian/Ubuntu FFmpeg можно установить пакетом `ffmpeg`.

```bash
cargo run --release
```

Откройте **http://127.0.0.1:8787**. Запускайте команду из корня репозитория: там находятся `web/` и демонстрационные файлы `demo/`.

Если программы находятся не в `PATH`, можно указать пути явно:

```bash
FFMPEG=/path/to/ffmpeg FFPROBE=/path/to/ffprobe cargo run --release
```

Переменная `RUSTCUT_BIND` меняет адрес сервера, `RUSTCUT_ROOT` — путь к репозиторию, `RUSTCUT_DATA_DIR` — папку данных. По умолчанию сервер слушает только `127.0.0.1`: **это однопользовательский прототип без авторизации, не выставляйте его в публичную сеть**. Данные, включая загруженные медиа и экспорты, остаются на машине сервера; никакие облачные сервисы приложением не используются.

## Как пользоваться

1. Нажмите **«Импортировать медиа»**, либо используйте демонстрационные материалы.
2. Дважды щёлкните по файлу или нажмите на `+` на его миниатюре. Перетащить файл также можно на дорожку V1/A1.
3. Щёлкните линейку таймлайна, чтобы поставить курсор. Выберите клип и нажмите `C` для разреза; тяните клип или его край для перемещения/обрезки.
4. `Пробел` — воспроизведение, стрелки — переход по кадрам, `Delete` — удаление, `Ctrl+Z` / `Ctrl+Shift+Z` — отмена/повтор.
5. **«Сохранить»** или `Ctrl+S` записывает проект на сервер. **«Экспорт»** рендерит MP4 и начинает его загрузку в браузере.

Сохранение не автоматическое. Файл `.rustcut/project.rustcut` содержит монтаж и ссылки на исходники в `demo/` и `.rustcut/uploads/`, а не копии всех медиа. Сохраните эти папки вместе: удаление `.rustcut/` удалит импортированные файлы и сохранённый проект. Это собственный простой формат прототипа, не `.prproj`; он пока не переносится между проектами через интерфейс. История отмены при перезапуске не сохраняется.

## Ограничения

Это ранний вертикальный срез, не полноценная замена Premiere: нет нескольких видеослоёв, переходов, эффектов, цветокоррекции, титров, прокси, аппаратного ускорения или совместимости проектов Adobe. V2/A2 в интерфейсе пока только обозначены. Наложения на одной дорожке запрещены. Нет фонового рендера с прогрессом и отменой, автоматического сохранения, управления проектами и защиты от одновременного доступа нескольких пользователей. Временная шкала фиксирована на 25 fps, а предпросмотр зависит от поддерживаемых браузером кодеков. Для серьёзной работы нужна дополнительная обработка переменной частоты кадров, таймкодов, цвета и нестандартных аудиопотоков.

## Проверки

```bash
cargo test
```

Модульные тесты проверяют целостность редактирования и сохранения. Интеграционный тест создаёт настоящий MP4, проверяет видео, чёрный промежуток и уровень звука; он пропускается, если `ffmpeg` или `ffprobe` отсутствуют. Демо-кадры созданы для проекта, аудио синтезировано. Шрифты Inter и JetBrains Mono распространяются со своими лицензиями в `web/fonts/`.
